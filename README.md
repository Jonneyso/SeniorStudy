# 上海高中生学习辅助项目

## 项目简介

本项目是一个为上海高中生提供学习辅助的Web应用，旨在整理和展示各科的学习知识，帮助学生更高效地复习和备考。目前已实现语文、数学、英语、物理、化学、地理、历史、政治、生物等多个学科的学习内容。

项目特色：按上海市高中课本体系组织各科内容，提供课本思维导图，并可点击章节节点查看知识点详解、考点分析以及来自上海市各重点中学大型考试的单元测试题。

## 学科内容

### 语文学科

- **上海高中必考古文古诗**：按教学进度分组整理，包含原文、注解、解析及高考真题考点

### 数学学科

- **代数**：方程与不等式、函数、数列等知识点
- **几何**：平面几何、立体几何、解析几何等知识点
- **微积分**：极限、导数、积分等知识点

### 英语学科

- **GVC单词知识**：按高考考察频率排序的高频词汇词组
- **语法知识**：时态、语态、从句、非谓语动词等语法知识点

### 物理学科

- **力学**：运动学、动力学、能量与动量等知识点
- **热学**：热力学第一定律、理想气体状态方程等知识点
- **电磁学**：电场、电路、磁场、电磁感应等知识点

### 化学学科

- **无机化学**：元素及其化合物、化学反应原理等知识点
- **有机化学**：烃类及其衍生物、生命中的有机化学等知识点
- **物理化学**：化学热力学、化学动力学等知识点

### 地理学科

- **自然地理**：地球运动、气候、水文等知识点
- **人文地理**：人口、城市、交通等知识点
- **区域地理**：中国地理、世界地理等知识点

### 历史学科

- **古代史**：先秦、秦汉、隋唐、宋元明清等历史时期
- **近代史**：鸦片战争至五四运动等历史时期
- **现代史**：新中国成立至今的历史

### 政治学科

- **经济生活**：商品与货币、分配与交换等知识点
- **政治生活**：公民的政治参与、政府职能等知识点
- **哲学生活**：唯物论、辩证法、认识论等知识点

### 生物学科

- **细胞生物学**：细胞的结构与功能、细胞代谢等知识点
- **遗传学**：遗传规律、DNA与基因等知识点
- **生态学**：生态系统、环境保护等知识点

## 如何启动服务

### 方法一：使用npm启动（推荐）

1. 打开命令提示符（Windows）或终端（Mac/Linux）
2. 导航到项目目录
3. 运行启动命令：
   ```bash
   npm start
   ```
4. 服务器将在端口8000上运行，访问：`http://localhost:8000`

### 方法二：使用Python脚本启动

1. 打开命令提示符（Windows）或终端（Mac/Linux）
2. 导航到项目目录
3. 运行启动脚本：
   ```bash
   python start_server.py
   ```
4. 服务器将在端口8000上运行，访问：`http://localhost:8000`

### 方法三：使用Python内置HTTP服务器

1. 打开命令提示符
2. 导航到项目目录
3. 启动HTTP服务器：
   ```bash
   python -m http.server 8000
   ```
4. 访问：`http://localhost:8000`

### 方法四：直接打开HTML文件

1. 找到项目根目录中的 `index.html` 文件
2. 双击该文件，将在默认浏览器中打开

> 注：本项目仅使用Python标准库，无需额外安装依赖（见 `requirements.txt`）。

## 功能说明

### 主页面

- 展示项目标题和简介
- 显示学科卡片（共9个学科）
- 学科卡片顺序：语文、数学、英语、物理、化学、地理、历史、政治、生物
- 每个学科卡片包含"课本内容"链接，点击进入课本思维导图模块

### 学科内容展示

- 点击学科卡片中的链接，进入对应的学科内容板块
- 内容默认隐藏，点击后仅显示当前选中的学科内容
- 每个学科按分类展示知识点
- 考点对应的高考真题/上海市重点高中期中期末真题默认折叠，点击考点标题展开

### 课本思维导图模块（新功能）

按上海市高中课本体系组织各科内容，每个科目包含若干本课本（如数学包含必修1-4、选修1-3共7本），每本课本以思维导图形式展示章节结构。

- **课本切换**：顶部标签栏可切换不同课本
- **思维导图**：以树状结构展示课本章节及对应知识点
- **章节详情**：点击带有 📖 图标的章节节点，弹窗展示：
  - **知识点列表**：章节涉及的知识点概览
  - **知识点详解**：每个知识点的详细讲解
  - **考点分析**：章节重点考点及考查方向
  - **单元测试题**：来自上海市各重点中学（上海中学、复旦附中、华东师大二附中、上海交大附中、七宝中学、建平中学等）大型考试（期中、期末、月考）的真题，包含题目、选项、答案和详细解析

### 语文古诗文模块

- 按教学进度分组展示古诗文
- 包含原文、注解、解析
- 考点包含高考真题/上海市重点高中期中期末考试试卷真题及解析

### 英语GVC单词模块

- GVC单词列表展示
- 单词中英文对照
- 按高考考察频率排序
- 包含例题及解析

### 英语语法模块

- 语法知识点分类展示
- 包含详细讲解和例句
- 考点包含高考真题/上海市重点高中期中期末考试试卷真题及解析

## 项目维护

### 数据更新

各学科数据文件位于 `subjects/` 目录下的对应学科目录中，按照以下格式组织：

- `data/` 目录存放JSON格式的数据文件
- 每个知识点包含：标题、内容、注解、解析
- 每个考点包含：关联的知识点、高考真题/上海市重点高中期中期末考试试卷真题、解析、参考答案

### 扩展学科

要添加新的学科或功能，请：

1. 在 `subjects/` 目录下创建新的学科目录
2. 按照现有学科的结构组织数据文件
3. 在 `src/components/` 目录下创建对应的组件文件
4. 在 `index.html` 中添加学科卡片和内容容器
5. 在 `main.js` 中初始化新组件
